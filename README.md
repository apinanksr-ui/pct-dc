# PCT-DC — เปลือกแอปสำหรับผู้บริหาร

หน้าเว็บหน้าเดียวที่ห่อหน้าผู้บริหารของระบบทะเบียนเอกสาร ให้ติดตั้งเป็นแอป
บนเดสก์ท็อปและมือถือได้ พร้อมไอคอนของบริษัท

## สำคัญ — ทำไมในไฟล์ชุดนี้ไม่มีลิงก์ระบบเลย

GitHub Pages แบบฟรีบังคับให้ repo เป็นสาธารณะ ไฟล์ทุกไฟล์ในนี้คนทั้งอินเทอร์เน็ตอ่านได้
จึง **ห้ามใส่ลิงก์ผู้บริหารหรือรหัส ?k= ลงในไฟล์ใดก็ตามในโฟลเดอร์นี้เด็ดขาด**

ลิงก์ถูกกรอกตอนติดตั้งครั้งแรกบนเครื่องแต่ละเครื่อง แล้วเก็บไว้ในเครื่องนั้นเท่านั้น
(localStorage) ไม่เคยถูกส่งไปเก็บที่ใด ใครเปิดที่อยู่ของแอปโดยไม่มีลิงก์จะเจอแค่หน้าตั้งค่า

## ไฟล์ในชุด

    index.html                หน้าเปลือก + หน้าตั้งค่าครั้งแรก + แถบสลับสามมุมมอง
    manifest.webmanifest      ชื่อแอปและไอคอน ทำให้ติดตั้งเป็นแอปได้
    sw.js                     แคชเฉพาะเปลือกกับไอคอน ไม่แคชข้อมูลเอกสารเลย
    icon-192 / 512 / maskable ไอคอนแอป
    apple-touch-icon.png      ไอคอนสำหรับ iPhone (พื้นทึบ)
    favicon-32.png / .ico     ไอคอนแท็บเบราว์เซอร์
    .nojekyll                 บอก GitHub ว่าไม่ต้องแปลงอะไร ให้เสิร์ฟไฟล์ตรง ๆ

## ข้อมูลไม่ถูกเก็บลงเครื่อง

service worker แคชเฉพาะไฟล์ในโฟลเดอร์นี้ ไม่แตะข้อมูลจาก script.google.com เลย
ตั้งใจให้เป็นแบบนี้ — ผู้บริหารต้องเห็นตัวเลขสดเสมอ การเห็นตัวเลขเก่าโดยไม่รู้ตัว
อันตรายกว่าการเปิดไม่ได้ ในงานที่มีข้อพิพาทเรื่องความล่าช้า
